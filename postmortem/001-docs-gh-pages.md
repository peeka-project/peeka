## 话题概述

该话题覆盖文档发布链路中的三类系统性问题：构建配置失配（theme/SCSS）、链接路径规则误用（`{% link %}` 与 permalink）、以及文档与真实功能漂移（快捷键与 CLI 命令）。问题在 2026-03-13 至 2026-03-18 连续出现，说明文档发布缺少构建验证、链接验证和内容一致性校验的统一门禁。

所有内部链接在点击后跳转到 `/peeka/peeka/...` 并 404。根因是 `{% link %}` 已自动 prepend `site.baseurl`，文档又手工追加一次前缀。

#### 类别

**修复前：**

```markdown
[detach]({% link commands/detach.md %})
```

### 复现

#### 前置条件
- 文档中 `{% link %}` 外包裹 `{{ site.baseurl }}`

#### 步骤
1. 打开文档站。
2. 点击任意内部链接。

#### 预期行为
跳转有效页面。

#### 实际行为
跳转到 `/peeka/peeka/...`，返回 404。

### 修复
